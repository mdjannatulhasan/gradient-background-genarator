# Gradient Background Generator

A beautiful and simple Next.js application for generating gradient backgrounds. Create stunning gradients with custom colors, directions, and presets.

## Features

-   🎨 **Color Picker**: Choose any two colors for your gradient
-   🧭 **Direction Control**: 8 predefined directions + custom angle slider
-   🎲 **Random Generator**: Generate random gradients with one click
-   📋 **Copy CSS**: Copy the generated CSS code to clipboard
-   🎯 **Presets**: 8 beautiful preset gradients to get started
-   📱 **Responsive**: Works perfectly on desktop and mobile
-   🌙 **Dark Mode**: Automatic dark mode support

## Getting Started

### Prerequisites

-   Node.js 18+
-   npm or yarn

### Installation

1. Clone the repository:

```bash
git clone <your-repo-url>
cd gradient-background-generator
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Run the development server:

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This project is configured for static export and can be deployed to any static hosting service.

### Build for Production

```bash
npm run build
```

The built files will be in the `out/` directory.

### Deploy to Vercel

1. Push your code to GitHub
2. Connect your repository to Vercel
3. Deploy automatically

### Deploy to Netlify

1. Build the project: `npm run build`
2. Upload the `out/` folder to Netlify
3. Or connect your GitHub repository for automatic deployments

### Deploy to GitHub Pages

1. Build the project: `npm run build`
2. Push the `out/` folder to a `gh-pages` branch
3. Enable GitHub Pages in your repository settings

## Usage

1. **Choose Colors**: Use the color pickers or input hex values
2. **Select Direction**: Pick from 8 predefined directions or use the angle slider
3. **Preview**: See your gradient in real-time
4. **Copy CSS**: Click the copy button to get the CSS code
5. **Try Presets**: Use the preset gradients for inspiration
6. **Randomize**: Generate random gradients for inspiration
